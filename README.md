# WISHLIST // ARCHIVE

A sharp, minimalist black-and-white catalog web application for curated Amazon wishlist items with custom categorization, rich descriptions, live in-place editing, and popout detail cards.

## Features

- **Monochromatic Aesthetic**: Swiss brutalist / editorial black-and-white interface with dark/light mode toggle.
- **Categorization**: Filter items by category, create custom categories, and assign items.
- **Interactive Item Popouts**: Click on any item to view high-res imagery, specs, tags, and direct Amazon links.
- **Live Editing**: Edit titles, descriptions, notes, tags, priority, and pricing directly in the app with `localStorage` persistence.
- **Instant Search & Sort**: Real-time multi-field search and flexible sorting (price, priority, alphabetical).
- **Data Export & Sync**: Export to JSON or Markdown, import JSON backups, and reset to defaults.

## Getting Started

Open `index.html` directly in your browser or run a local static server:

```bash
# Using Node / npx
npx serve .

# Or using Python
python -m http.server 3000
```
